# Weekly Affiliate Report

Прототип еженедельного отчёта для affiliate-команды.

## Что работает

- общий демо-доступ без логинов, паролей и ролей;
- вкладки «Отчёты» и «Создать новый отчёт»;
- автоматическое сохранение;
- проверка обязательных полей перед отправкой;
- фиксация отправленного отчёта в отдельном читаемом виде;
- один общий тред комментариев внизу отчёта: можно добавлять новые сообщения и отвечать на любое из них;
- быстрые показатели в списке отчётов: FTD, активные, новые партнёры, новые сделки и реактивации;
- пять главных цифр сразу под датой: FTD, активные, новые партнёры, новые сделки и реактивации;
- новые партнёры, реактивации и отправленные сделки с автоматическим подсчётом по заполненным строкам;
- план по поиску вводится внутри блока «Привлечение», а в отчёте ровно за следующую неделю показывается там же над фактически найденными партнёрами;
- рост и падение действующих партнёров с раскрывающимся списком;
- проблемы партнёров и действия менеджера;
- план на следующую неделю без отдельного блока обязательной отчётности;
- отдельный блок с главными приоритетами, проблемами и достижениями;
- достижения обязательны, варианта «достижений нет» в новых отчётах нет;
- блок «Результаты» с динамикой командного FTD по неделям и таблицей менеджеров по всем числовым показателям;
- отсутствие отчёта в таблице видно отдельно и не считается нулевым результатом;
- пояснение и пример по кнопке `?` у каждого раздела;
- неограниченное добавление строк во всех списках;
- общая кнопка «Сохранить» в каждом списке: она завершает текущую строку и сворачивает её без создания лишней пустой строки;
- компактные сворачиваемые строки, чтобы большие списки не превращались в полотно форм.
- пять сворачиваемых разделов: при входе видны только названия;
- отдельные отметки об отсутствии проблем; приоритеты и достижения заполняются обязательно;
- обязательное пояснение, если менеджер не занимался поиском.

## Важно про демо

Данные по-прежнему хранятся только в `localStorage` текущего браузера. График и рейтинг собираются только из отчётов, созданных в этом же браузере; открытие публичной ссылки на другом устройстве не показывает общую командную историю. Все отчёты и комментарии доступны без разделения прав.

Для рабочей версии нужно подключить серверную базу, нормальную авторизацию, список сотрудников и права руководителя.

## Запуск

```bash
npm run check
npm run build
npm run preview
```

Готовая статическая версия находится в `dist/static`.
