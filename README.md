# Weekly Affiliate Report

Прототип еженедельного отчёта для affiliate-команды.

## Что работает

- вход только по паролю, без логина;
- отдельные данные для каждого пароля и каждой недели;
- автоматическое сохранение;
- итоги недели: FTD и активные партнёры;
- новые партнёры, реактивации и отправленные сделки с автоматическим подсчётом по заполненным строкам;
- рост и падение действующих партнёров с раскрывающимся списком;
- проблемы партнёров и действия менеджера;
- план на текущую неделю с апдейтом по итогу;
- отдельный блок с главными приоритетами, проблемами и достижениями;
- пояснение и пример по кнопке `?` у каждого раздела;
- неограниченное добавление строк во всех списках.
- компактные сворачиваемые строки, чтобы большие списки не превращались в полотно форм.
- шесть сворачиваемых разделов: при входе видны только названия;
- отдельные отметки об отсутствии проблем и достижений; приоритеты заполняются обязательно;
- обязательное пояснение, если менеджер не занимался поиском.

## Важно про демо

Пароль в этой версии разделяет локальные рабочие пространства, но не является настоящей авторизацией. Данные лежат в `localStorage` конкретного браузера и не синхронизируются между устройствами. Любой пароль длиной от четырёх символов создаёт отдельное пространство.

Для рабочей версии нужно подключить серверную базу, нормальную авторизацию, список сотрудников и права руководителя.

## Запуск

```bash
npm run check
npm run build
npm run preview
```

Готовая статическая версия находится в `dist/static`.
